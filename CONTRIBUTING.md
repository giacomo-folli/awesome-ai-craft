# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

- Search previous suggestions before making a new one, as yours may be a duplicate.
- Make an individual pull request for each suggestion.
- Use the standard entry format:
  `* [ProjectName](https://url) - Brief description.`
- Keep descriptions short, concise, and objective (aim for a single clear sentence).
- Ensure new categories or projects align with AI creative craft (digital art, audiovisual generation, physical crafts, design, game dev).
- Prefer linking directly to the primary GitHub repository or the official product homepage.
- Check your spelling, capitalization, and grammar.
- Ensure all markdown links are valid and anchor tags in the Table of Contents are properly updated.

Thank you for helping keep **Awesome AI Craft** fresh and comprehensive!
